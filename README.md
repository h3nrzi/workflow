فازهای صفر تا دو دو فرمان شروع و جمع‌بندی دارند. در فاز دو مشاور، پرامپت ساخت و اصلاح را در جریان گفتگو ارائه می‌کند؛ جمع‌بندی پس از ارزیابی یا توقف است. فازهای سه تا هشت فرمان‌های مستقل شروع طراحی، تدوین spec، تیکت‌بندی، اجرای کل فاز یا یک تیکت مشخص و ارزیابی دارند. ادامهٔ نقشه در شش و هشت نیز فرمان جداست. شروع طراحی، اجرای کد یا استقرار را آغاز نمی‌کند؛ ایجاد نقشه پایان تصمیم‌ها نیست. پایان طراحی، پایان اجرای فاز و پذیرش انسانی جدا هستند.

## بستهٔ مرجع و شواهد

یک بستهٔ مرجع محصول به‌تدریج کامل می‌شود. نسخه، مرحله، منابع، فرضیات، تصمیم معتبر و جایگزین‌شده، محدوده، رفتار، مجوزها، نتایج و مسائل باز روشن‌اند. شناسه‌های FLOW / SCREEN / INT / AC و DEC / TEST / OPEN پایدار و checkpointهای CP-2 تا CP-8 به نسخهٔ پیشین متصل‌اند. از فاز سه محل معتبر اسناد داخل مخزن پروژه است؛ Agent در سشن تازه آن‌ها را می‌خواند. تعارض سند یا هویت مبهم تیکت به تصمیم روشن نیاز دارد؛ ورودی اختیاری خالی مجوز حدس نیست.

تأیید فهم توسعه‌دهنده، تصمیم کارفرما، پذیرش ریسک، توافق مالی و مجوز بررسی، ابزار، توسعه و انتشار مستقل‌اند. مثال پیوستهٔ TaskFlow آموزشی است؛ CP-2 آن به علت نبود سورس مسدود و ادامهٔ CP-3 تا CP-8 اجرا‌نشده و شرطی است. AC-01/02 و TEST-01 شواهد واقعی ندارند؛ سناریوهای پیشنهادی AC-03/04/05 رفتار مصوب نیستند. هیچ نمونهٔ فرضی Passed یا Failed جای شاهد واقعی نیست.

مسیر ساخت نمونه فقط ابزارهای vibe coding است؛ بررسی پیشینی قابلیت خروج سورس شرط انتخاب ابزار نیست. هنگام تحویل، سورس و شواهد لازم‌اند. پروتوتایپ فقط فرانت بدون بک‌اند واقعی است؛ خروجی ابزار برای سرویس و وابستگی ناخواسته بررسی می‌شود. راهنمای Replit تجربی است و صفحهٔ قدیمی Stitch از مسیر فعال ساخت کنار رفته است. برای هر بررسی انتظار، مشاهده، نسخه، شاهد و Passed / Failed / Blocked / Not Tested ثبت می‌شود.

تعریف رفتار MVP مرجع درستی تست است، نه رفتار فعلی سورس. فناوری از سورس واقعی کشف می‌شود؛ حفظ سورس قابل‌قبول ترجیح دارد و تغییر مستدل ممکن است. مقصد محصول monorepo فول‌استک است؛ قید JS/TS مربوط به اپلیکیشن و ابزار مرتبط است و زبان دیتابیس/زیرساخت را محدود نمی‌کند. نقص مانع عبور رفع می‌شود؛ انتقال نقص نیازمند تصمیم، اثر، مسئول و موعد است.

## ساختار و اجرا

HTML معنایی فارسی و RTL و CSS مشترک؛ بدون framework یا build. `assets/prompt.js` ورود، پیش‌نمایش و کپی کارگاه‌ها و مرکز پروتوتایپ را انجام می‌دهد؛ `assets/phase-0-navigation.js` فهرست و منوی باریک را مدیریت می‌کند. ورودی ذخیره یا ارسال یا اجرا نمی‌شود؛ استفاده از پرامپت در Agent بیرونی اقدام جداست.

از ریشهٔ مخزن اجرا کنید:

```sh
python3 -m http.server 8000
```

نخست [نمای کلی](http://localhost:8000/) را باز کنید و کارت فاز سه را انتخاب کنید. نصب وابستگی لازم نیست. مجموعهٔ تست یا framework جدید اضافه نشده است. [راهنمای ارزیابی کامل این نسخه](docs/development-phases-evaluation.md) ورودی، اقدام، انتظار و checkpoint هر هشت تیکت و شواهد واقعی را تفکیک می‌کند. پذیرش انسانی تا گزارش مشاهدهٔ کاربر pending است.
