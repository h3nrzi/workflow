# ورک‌فلو؛ راهنمای عملی ساخت محصول فول‌استک با AI

برای توسعه‌دهندهٔ ارشد JS/TS که می‌خواهد از درخواست مشتری به محصول قابل تحویل برسد. هر اقدام توضیح کوتاه، مثال TaskFlow، تمرین پروژهٔ خواننده، پرامپت قابل بررسی و معیار پایان دارد. آموزش و کار عملی در همان صفحه‌اند.

| فاز | خروجی قابل بررسی |
| --- | --- |
| [۰: فهم درخواست](v2/phases/phase-0.html) | مسئله، شواهد/مجهول‌ها، حدود اختیار و گام مجاز |
| [۱: تعریف محصول و MVP](v2/phases/phase-1.html) | جریان کامل، محدوده/خارج آن و رفتار قابل ارزیابی |
| [۲: ساخت و ارزیابی فرانت](v2/phases/phase-2.html) | پروژهٔ لوکال، فرانت با mock، تست و راهنمای ارزیابی |
| [۳: طراحی بک‌اند](v2/phases/phase-3.html) | مدل، هویت، عملیات/خطا/دسترسی و قرارداد اتصال |
| [۴: ساخت و اتصال واقعی](v2/phases/phase-4.html) | اول یک جریان UI تا API/دیتابیس، سپس باقی MVP |
| [۵: استقرار و تحویل](v2/phases/phase-5.html) | انتشار بررسی‌شده، بازگشت، بازیابی، پایش و مسئول عملیات |

فازهای ۰ و ۱ کار مشترک توسعه‌دهنده و LLM هستند. از فاز ۲ ایجنت لوکال سورس، ترمینال و مرورگر مجاز را بررسی می‌کند و وضعیت و شواهد را در مخزن نگه می‌دارد. طراحی، ساخت و انتشار اختیارهای جدا دارند؛ پس از فرمان اجرا، کار آمادهٔ داخل محدوده بدون اجازهٔ تکراری هر تیکت پیش می‌رود. تصمیم تازهٔ محصول، هزینه یا دسترسی به صاحب اختیار برمی‌گردد. ابهام فقط کار وابسته را می‌بندد.

[TaskFlow](v2/journey.html) مسیر آموزشی مشخص React/Vite/TypeScript در frontend، Express/TypeScript در backend، PostgreSQL، Auth0 و Render دارد؛ فناوری پروژهٔ خواننده با نیاز و توان نگهداری خودش انتخاب می‌شود. مثال‌ها شاهد اجرای واقعی نیستند. مهارت‌های لازم از فاز ۳ در محل استفاده معرفی می‌شوند.

[قرارداد مراحل و شواهد](v2/contracts.html) ورودی/خروجی، اختیار، فهرست ورود و معیار آمادگی را تعریف می‌کند. نسخهٔ سند و commit واقعی جدا از شمارهٔ مرحله ثبت می‌شوند. راهنمای ارزیابی، تست و پذیرش انسانی نتیجه‌های مستقل‌اند؛ پذیرش تا گزارش مشاهده pending می‌ماند.

## اجرای محلی

سایت HTML فارسی RTL با CSS و JavaScript مشترک است و build یا framework نیاز ندارد. در ریشه:

```sh
python3 -m http.server 8000
```

[صفحهٔ اصلی](http://localhost:8000/) را باز کن، وارد فاز صفر شو، درخواست پروژهٔ خودت را وارد کن، پیش‌نمایش را بخوان و پرامپت را کپی کن. سایت ورودی را ذخیره، ارسال یا اجرا نمی‌کند؛ بستهٔ مرجع را خودت در محل مجاز نگه دار.

برای بررسی مقصدها، fragmentها و شناسه‌های تکراری:

```sh
python3 scripts/check-links.py
```

این بررسی جای مرورگر، clipboard و ارزیابی انسانی را نمی‌گیرد. شواهد واقعی پیاده‌سازی در `docs/evaluations/practical-workflow-*.md` ثبت می‌شوند؛ به نسخه و دامنهٔ هر رکورد توجه کن. انتشار عمومی سایت یا ساخت یک محصول مشتری با اجرای این مخزن انجام نمی‌شود.
