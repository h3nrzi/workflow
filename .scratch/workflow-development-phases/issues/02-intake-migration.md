# 02: تکمیل آموزش و کارگاه فاز سه: تحویل‌گیری و مهاجرت

**What to build:** توسعه‌دهنده از بستهٔ تحویل فاز دو تا بررسی سورس واقعی، تصمیم فناوری فرانت و طرح و اجرای مهاجرت محدود به monorepo قابل اجرا، یک راهنمای کامل و فرمان‌های مستقل در اختیار داشته باشد. آموزش، کارگاه، دسترسی از فاز دو و پشتیبانی مشترک فرمان‌ها در یک برش قابل بررسی تکمیل شوند. این کار پیاده‌سازی سایت راهنماست، نه مهاجرت محصول مشتری.

**Blocked by:** 01 — اصلاح مسیر ساخت پروتوتایپ و تحویل فاز دو.

**Status:** needs-info

- [x] آموزش برای هر فعالیت اصلی هدف، چرایی، پیش‌نیاز و ورودی، روش، مثال پیوسته، شکست و بازگشت، خروجی خوب، شرط پایان و اقدام بعدی داشته باشد و بدون اجرای LLM نیز قابل استفاده باشد.
- [x] بررسی اولیه پیش از تغییر ساختار شامل نصب، اجرا، build، وابستگی‌های بیرونی، شبیه‌سازی‌ها، بک‌اند احتمالی و شواهد مسیرهای اصلی باشد. سورس اجرا‌نشدنی مانع پایان مهاجرت معرفی شود و بررسی اجرا‌نشده موفق گزارش نشود.
- [x] حفظ یا تغییر فناوری فرانت و ادامهٔ سورس یا بازسازی با دلیل، کیفیت، هزینه و مسیر روشن تصمیم‌گیری شوند؛ تعارض تغییر بنیادی با مرز مهاجرت محدود آشکار شود. محدودیت میزبانی، هزینه و سرویس‌ها زود بررسی شوند و انتخاب بک‌اند بی‌دلیل جلو نیفتد.
- [x] مقصد monorepo فول‌استک باشد؛ مهاجرت اولیه فقط ساختار، نصب، اجرا و build را برقرار کند. پوشش کامل E2E، اصلاح همهٔ رفتارها و ریفکتور داخلی به فازهای بعد تعلق داشته باشند. قید JS/TS به کد اپلیکیشن و ابزارهای مرتبط محدود باشد و زبان دیتابیس و زیرساخت را محدود نکند.

- [x] هر فرمان پیش‌نمایش خوانا و کپی مستقل داشته باشد؛ پشتیبانی مشترک با حفظ رفتار کارگاه‌های موجود، ورودی اختیاری مخصوص همان فرمان و فرمان بدون ورودی را پشتیبانی کند. تغییر ورودی یک فرمان روی دیگری اثر نگذارد؛ فارسی چندخطی، نویسه‌های خاص، الگوهای دلار و متن شبیه HTML یا JavaScript عیناً منتقل شوند و اجرا نشوند.
- [x] موفقیت کپی فقط پس از موفقیت واقعی اعلام شود؛ شکست کنترل‌شده به پیش‌نمایش قابل انتخاب و کپی دستی برسد. وضعیت با فناوری کمکی خواندنی، فوکوس قابل استفاده و رابط در عرض باریک خوانا باشد. دادهٔ فرم ذخیره یا ارسال نشود و سایت Agent را اجرا نکند.
