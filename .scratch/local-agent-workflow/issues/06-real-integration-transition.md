# 06: ورود به فاز ۴ جدید — اتصال واقعی

**What to build:** خواننده از قراردادهای طراحی بک‌اند به مسیر آموزش و فرمان‌های ساخت اولین جریان واقعی از فرانت تا API و دیتابیس برسد و سپس تکمیل MVP را دنبال کند. محتوای فاز ۷ قبلی با هویت جدید و ارتباط روشن با فرانت شبیه‌سازی‌شده عرضه شود.

**Blocked by:** 05 — ورود به فاز ۳ جدید — طراحی بک‌اند.

**Status:** ready-for-agent

**Resolution:** resolved (technical implementation)

**Human acceptance:** pending

- [x] آموزش و کارگاه اتصال با شماره، عنوان، ناوبری، ارجاع و checkpoint جدید قابل استفاده باشند و مسیر ورود از طراحی بک‌اند و ارجاع قدیمی روشن باشد.
- [x] ورودی شامل رفتار مصوب، سورس فرانت، قراردادهای بک‌اند، مرزهای داده و mock، تست‌ها و اختیار اجرای مربوط باشد. اختیار ساخت یا اتصال واقعی از صرف وجود طراحی یا تأیید بازطراحی ورک‌فلو استنتاج نشود.
- [x] ابتدا یک هدف معنادار کاربر از فرانت تا API و دیتابیس واقعی ساخته و بررسی شود؛ دلیل انتخاب جریان اول روشن باشد و ساخت همهٔ بک‌اند پیش از اولین اتصال شرط مسیر نشود.
- [x] برای هر جریان تغییر فرانت، عملیات، داده، قواعد دسترسی، حالت‌های انتظار و خطا و زمان جایگزینی شبیه‌سازی معلوم باشد. تغییر رفتار تازه به تصمیم محصول برگردد و قرارداد mock الزام بک‌اند باقی نماند.
- [x] سناریوهای رفتاری فاز ۲ روی محصول متصل دوباره اجرا شوند؛ تست منطق و تعامل API و دیتابیس متناسب با ریسک اضافه شوند و موفقیت شبیه‌سازی شاهد امنیت یا صحت اتصال واقعی معرفی نشود.
- [x] پایان اتصال شامل نبود اتکای پنهانی به موفقیت ساختگی در مسیر واقعی، شواهد بررسی‌های لازم و مسائل باز روشن باشد؛ ورودی انتشار و تحویل با نسخه و مجوزها مشخص شود.
- [x] محتوای لازم و مهارت همراه فاز قبلی با نگاشت جدید حفظ شوند؛ آموزش دارای روش، مثال، شکست و معیار پایان باشد و اجرای مثال آموزشی ادعا نشود.
- [x] فرمان‌ها با ورودی، پیش‌نمایش و کپی مستقل، متن فارسی چندخطی و نویسه‌های خاص و مسیر شکست کپی بررسی شوند؛ ناوبری، fragmentها، صفحه‌کلید و عرض‌های دسکتاپ، تبلت و موبایل ارزیابی شوند.
- [x] بررسی‌های متناسب و code review انجام و در همان چت راهنمای ارزیابی همین تیکت، شواهد واقعی preflight و نخستین اقدام کاربر ارائه شود؛ پذیرش انسانی pending بماند. ساخت محصول مشتری یا اتصال به سرویس واقعی برای پیاده‌سازی این تیکت انجام نشود.
