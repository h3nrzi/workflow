## Agent skills

### Issue tracker

Before reading or writing issues or specs, read `docs/agents/issue-tracker.md`.
Issues live as local Markdown under `.scratch/<feature>/`.

### Triage labels

Before triaging issues, read `docs/agents/triage-labels.md`.
Use the five default triage roles as local status values.

### Domain docs

Before exploring the codebase, read `docs/agents/domain.md`.
Use a single-context layout: root `GLOSSARY.md` and `docs/adr/`.
