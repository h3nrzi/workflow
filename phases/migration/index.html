ورودی / بدون ارسال به سایت

سه ورودی لازم را آماده کن

این فرم فقط متن پرامپت‌های قابل کپی رو در مرورگر می‌سازه. پیش از انتقال اطلاعات به LLM بیرونی، نام مشتری، دادهٔ شخصی، کلیدها و اطلاعات محرمانه را حذف کن. اگر گزارش هنوز نداریم، فیلد را خالی بگذار؛ LLM اول باید مانع را صریح بگه.

ورودی‌های LLM اولاطلاعات واقعی یا «نامعلوم» بنویس؛ داده‌ها در این سایت ذخیره نمی‌شوند.
هنوز متنی وارد نشده؛ برای شروع از Handoff فاز دو استفاده کن.
مرز شواهد: اگر فقط اسم Framework یا یک پوشه را حدس زده‌ای، با برچسب «فرضیه» بنویس. پرامپت‌ها برای «فهمیدن» ساخته می‌شوند، نه برای اعلام اینکه پروژه قبلاً بازرسی شده.

PROMPT / LOCAL AGENT

قبل از اجرا، یک Inventory فقط-خواندنی بگیر

این متن برای Local Coding Agent است، نه LLM اول. هدفش شناخت واقعی کد بدون اجرای دستورات ناخواسته است. خروجی رو مرور کن و خلاصهٔ مجاز آن را به LLM اول برگردون.

متن دستور Coding Agent

نکتهٔ عملی

دستور بازرسی، جایگزین اجرای واقعی پروتوتایپ نیست. اجرای Baseline، نصب وابستگی یا اجرای تست فقط بعد از بررسی ایمنی و مجوز جدا انجام می‌شه؛ نتیجهٔ هر اجرا باید مستند به دستور/فایل و مشاهدات واقعی باشد.

وابستگی واقعی / Matt Pocock Skills

Skills را در Monorepo و Agent خودت آماده کن

راه نصب باید با Agent انتخابی و نسخهٔ فعلی مخزن Skills سازگار باشه. مستند اصلی mattpocock/skills مرجعه. برای استفاده از grill-with-docs دو Skill وابستهٔ grilling و domain-modeling هم لازم‌اند.

install — review CLI & target agent before running
npx skills add mattpocock/skills --skill=grill-with-docs
npx skills add mattpocock/skills --skill=grilling
npx skills add mattpocock/skills --skill=domain-modeling

# in the coding agent, inside the intended repo
/setup-matt-pocock-skills
/grill-with-docs

می‌تونی سایر Skillهای مسیر (to-spec، to-tickets، implement و code-review) رو بر اساس کار چندمرحله‌ای نصب کنی. دستور Setup تنظیمات Tracker و مستندات رو می‌سازه؛ خروجی‌هاش رو قبل از Commit بررسی کن. برای Local Markdown لزوماً Tracker آنلاین لازم نیست.

پیش از Grill

  • کار در ریپازیتوری درست، Branch درست و محل نوشتن مجاز انجام می‌شود.
  • وابستگی‌های Skill بارگیری شده‌اند؛ فقط وجود عنوان grill-with-docs کافی نیست.
  • بدان که اصطلاحات در GLOSSARY.md و تصمیم‌های بزرگ در docs/adr/ نوشته می‌شوند؛ وجود یا نبود ADR را کنترل کن.
  • اگر Monorepo چند حوزهٔ مستقل دارد، Setup ممکن است GLOSSARY-MAP.md و گلوسری هر حوزه را مطرح کند.
  • اگر Skill پرسش‌ها را یک‌باره پرسید یا هیچ اثر مستندی نداشت، بارگیری Skillهای وابسته و محل اجرا را بررسی کن.

این دستورات راهنمای اجرای دستی‌اند؛ روی این سایت نصب یا اجرا نمی‌شوند. اگر نسخهٔ CLI یا Skill تغییر کرد، راهنمای رسمی همان نسخه اولویت داره.

PROMPT / STEPS

بعد از هر نتیجهٔ Agent، پرامپت مرحلهٔ بعد رو بساز

LLM اول رو در همان سشن Kickoff نگه دار. گزارش واقعیِ Local Agent رو وارد کن، مرحلهٔ فعلی رو انتخاب کن و درخواست مرحلهٔ بعد رو بساز. این درخواست به LLM اول می‌ره تا دستور هدفمند برای Agent تولید کنه؛ خودش Skill رو اجرا نمی‌کنه.
