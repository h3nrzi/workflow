# مستندات جاری با یک مسیر معتبر و بدون آرشیو نسخه‌ها

در مصاحبهٔ ۲۰۲۶-۱۰-۲۹، حفظ نسخهٔ ۱ و نمایش نگاشت یا تاریخچهٔ نسخه‌ها در مستندات جاری رد شد. مستندات آموزشی فقط مسیر معتبر فعلی را توضیح می‌دهند و تغییرات تازه نیازمند توضیح نسبت خود با نسخه‌های پیشین نیستند؛ تاریخچهٔ Git دست‌نخورده می‌ماند. این تصمیم جای الزام حفظ صفحات و آدرس‌های آموزشی قدیمی در استاندارد مستندات و صفحهٔ نگاشت نسخه‌ها را می‌گیرد؛ یکپارچگی مسیر یادگیری فعلی بر سازگاری با مسیرهای قدیمی اولویت دارد. حذف عمومی سوابق داخلی پروژه از این تصمیم نتیجه نمی‌شود.

مسیر شش‌فازی و مسئولیت انسان و ایجنت حفظ می‌شوند؛ آموزش و کارگاه در هر مرحله یکپارچه خواهند شد. کاربر برداشت مشترک نهایی مصاحبه را تأیید کرده است؛ این سند تصمیم را ثبت می‌کند و به‌تنهایی شاهد پیاده‌سازی یا پذیرش انسانی سایت نیست.
