# Triage labels

For local Markdown issues, record these role strings in the `Status:` line.

| Role | Status value | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer needs to evaluate the issue |
| needs-info | needs-info | Waiting on reporter for more information |
| ready-for-agent | ready-for-agent | Fully specified, ready for an agent |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

When a skill asks to apply a triage label, update the issue's `Status:` line.
Edit the Status value column to customize this vocabulary.
